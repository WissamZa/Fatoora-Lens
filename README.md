# Fatoora Lens

تطبيق **عدسة فاتورة** لمسح وإدارة فواتير ZATCA.

تطبيق Flutter لقراءة QR الخاص بالفواتير الإلكترونية السعودية (ZATCA TLV Base64)، واستخراج اسم المحل والرقم الضريبي والتاريخ والوقت والمبلغ والضريبة.

## المزايا

- مسح بالكاميرا أو من صورة.
- الصفحة الرئيسية تعرض آخر خمس فواتير مع بحث شامل.
- تبويب للمحلات؛ كل محل يعرض الرقم الضريبي، ملاحظته، إجماليه، وفواتيره من الأقدم إلى الأحدث.
- تبويب تحليل برسوم بيانية وإجمالي كل محل وإجمالي جميع المحلات.
- وضع ليلي ولغتان: العربية والإنجليزية.
- تعديل وحذف الفواتير، وملاحظة اختيارية لكل فاتورة وملاحظة عامة لكل محل.
- تصدير CSV، نسخة احتياطية JSON واستردادها، وإنشاء PDF مع اختيار الفواتير.

## التشغيل

```bash
flutter pub get
flutter run
```

## Release محلي

```bash
flutter build apk --release --split-per-abi --tree-shake-icons \
  --obfuscate --split-debug-info=build/symbols
```

يستخدم البناء `split-per-abi` لتقليل حجم كل APK، وML Kit غير المضمن لتقليل حجم التطبيق الأساسي.

## GitHub Release

الدفع إلى Tag يبدأ بحرف `v` يشغل [Workflow الإصدار](.github/workflows/release.yml)، ويبني APK منفصلًا لكل معمارية ثم يستخدم `gh release create` لنشره تلقائيًا.

```bash
git tag v1.0.0
git push origin v1.0.0
```

## صيغة ZATCA

يعتمد المحلل على معيار TLV: الوسم 1 اسم البائع، 2 الرقم الضريبي، 3 وقت الإصدار، 4 الإجمالي شامل الضريبة، و5 إجمالي الضريبة.
