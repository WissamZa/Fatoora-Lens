# عدسة فاتورة | Fatoora Lens

تطبيق Flutter لقراءة رمز QR الخاص بالفواتير الإلكترونية السعودية (ZATCA TLV Base64)، واستخراج اسم المحل والرقم الضريبي والتاريخ والوقت والمبلغ والضريبة، وتخزينها محليًا على الجهاز مع تحليلات وتصدير.

- الحزمة: `com.fatooralens.app`
- المنصات: Android وiOS
- التخزين: قاعدة بيانات محلية (sqflite) — لا يرسل التطبيق أي بيانات إلى الخارج.

## المزايا

### المسح وإدارة الفواتير
- مسح رمز QR بالكاميرا مباشرة أو من صورة محفوظة.
- مسح باركود رقم الفاتورة (Code128/39، EAN، UPC، ITF، Codabar) داخل محرر الفاتورة.
- الصفحة الرئيسية تعرض آخر 5 فواتير مع بحث شامل وتصفية حسب المبلغ (أكبر/أصغر/يساوي).
- زر «عرض الكل» يفتح نافذة مستقلة بكل الفواتير مع بحث وفرز: الأحدث، الأقدم، المبلغ الأعلى/الأدنى، واسم المحل.
- تعديل وحذف الفواتير، مع ملاحظة اختيارية لكل فاتورة وملاحظة عامة لكل محل.
- إرفاق صورة الفاتورة من الكاميرا أو المعرض مع شاشة قص وتدوير سهلة بحيث تظهر الفاتورة فقط.
- اسم المحل بالعربية من QR، مع حقل اختياري للاسم بالإنجليزية.
- تبويب المحلات: يعرض كل محل الرقم الضريبي وملاحظته وإجماليه وفواتيره من الأقدم إلى الأحدث.

### التحليل
- رسوم بيانية: الإجمالي حسب المحل (أعمدة)، اتجاه الإنفاق الشهري (خط)، ونسبة كل محل (دائري).
- الضغط على أي رسم يفتحه بملء الشاشة بالوضع الأفقي لعرض جميع البيانات (كل المحلات وكل الأشهر) مع تمرير عند الحاجة.
- بطاقات ملخص: إجمالي كل المحلات، إجمالي الضريبة، عدد الفواتير، ونسبة كل محل من الإجمالي.
- جميع المبالغ تعرض رمز الريال السعودي الرسمي.

### التصدير والمشاركة
- تقرير PDF مع اختيار الفواتير: الاسم العربي للمحل فوق الاسم الإنجليزي عند توفره، ورمز الريال الرسمي بجانب كل المبالغ والإجماليات، بأحجام خط موحدة تتكيّف مع طول المحتوى.
- تصدير CSV بترميز UTF-8 (يفتح مباشرة في Excel).
- نسخة احتياطية JSON لكل البيانات واستردادها.

### عام
- نافذة «حول التطبيق» في الإعدادات تعرض اسم التطبيق والإصدار والمطور والوصف.
- وضع ليلي ولغتان: العربية (افتراضيًا) والإنجليزية.

## بنية المشروع

```
lib/
├── main.dart                  # نقطة البداية وتهيئة قاعدة البيانات
├── app.dart                   # الثيم واللغة والجذر
├── l10n.dart                  # نصوص التطبيق (عربي/إنجليزي)
├── config/
│   └── app_info.dart          # بيانات نافذة «حول التطبيق» (المطور/الوصف/التواصل)
├── data/
│   └── database_service.dart  # sqflite: الجداول والاستعلامات والنسخ الاحتياطي
├── models/                    # Invoice وShop
├── screens/                   # الرئيسية، المحلات، التحليل، الإعدادات، الماسح، تصدير PDF، كل الفواتير
├── services/
│   ├── zatca_qr_parser.dart   # محلل TLV
│   └── export_service.dart    # تصدير CSV وPDF والمشاركة
└── widgets/                   # بطاقة الفاتورة، محرر الفاتورة، رمز الريال
```

- لتعديل بيانات «حول التطبيق» (المطور، الوصف، التواصل): عدّل `lib/config/app_info.dart` فقط.
- لإضافة نص جديد: أضفه في `lib/l10n.dart` في الخريطتين `_ar` و`_en`.

## رقم النسخة

يُدار رقم النسخة من مكان واحد: سطر `version` في `pubspec.yaml` (مثل `1.0.7+1000007`).

- نافذة «حول التطبيق» في الإعدادات تقرأ الرقم تلقائيًا عند التشغيل — لا حاجة لتعديل أي ملف آخر.
- عند الإصدار: أنشئ Tag بنفس الرقم (`git tag v1.0.8`)، وبناء APK النهائي يستخدمه كـ `versionName`.

## صيغة ZATCA

يعتمد المحلل على معيار TLV: الوسم 1 اسم البائع، 2 الرقم الضريبي، 3 وقت الإصدار، 4 الإجمالي شامل الضريبة، و5 إجمالي الضريبة.
